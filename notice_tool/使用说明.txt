智屏安播 串口指令 使用说明
================================

连接：电脑 USB 接板子的 CH340 串口（设备管理器里是 USB-SERIAL CH340 (COMx)）
串口助手设置：921600 bps（注意：不是 115200），8-1-none，发送用“文本”模式（不是 HEX），编码 UTF-8，结尾加不加回车都可以

图形界面（推荐演示用）：双击 智屏安播控制台.exe（装字库时会在同一个文件夹找 FONT.BIN）
  选 CH340 串口 → 连接 → 按钮操作：启事（寻人 / 寻物 / 招领、加照片、撤销）、应急（三级 + 类型 + 消音 + 解除）、
  日常（通知、图片字幕、字幕 / 波形 / 分辨率 / 轮播 / 音乐开关、翻页）、系统（装字库、自己输入指令）
  照片：点“选择照片并发送…”选 jpg / png，程序自己转成 PHOTO.BIN（和 gen_photo 结果完全一样）并连续发送（约 10 秒，不用串口助手分包）
  不用安装；源码 control_panel.cs，改了以后双击 build_panel.bat 重新编译。和串口助手不能同时连同一个串口

指令格式：口令 空格 指令      （口令默认 8848；空格可以省，8848音乐开 也行）
  8848 通知 寻物启事：一卡通遗失于图书馆二楼，请联系保卫处
  8848 撤销通知
  8848 字幕关        8848 字幕开        （每张图下面的滚动字幕，和 KEY3 长按是同一个开关，断电不丢）
  8848 波形关        8848 波形开        （字幕上方的音频波形，和 KEY3 + Key2 同时按是同一个开关，断电不丢）
  8848 分辨率开      8848 分辨率关      （左上角显示这张图的原图分辨率，例如 1078x1262 -> 640x480；拨码 SW4 拨开也是显示，以最后一次操作为准）
  8848 轮播关        8848 轮播开        （自动轮播，和 Key4 短按是同一个开关）
  8848 音乐关        8848 音乐开
  8848 消音                             （应急时关掉警报声，画面告警保持）
  8848 下一张        8848 上一张
  8848 帮助
  8848 装字库
  8848 寻人 / 寻物 / 招领 内容、8848 启事、8848 撤销1~4、8848 撤销全部（见下面“启事”）
  8848 照片1 ~ 照片4                    （给第几条启事加照片，见下面“启事照片”）
  8848 字幕1 ~ 字幕4 内容               （改第几张图下面的滚动字幕，断电不丢，见下面“改图片字幕”）

改图片字幕（PIC1~PIC4 下面那条滚动字幕，断电不丢）：
  8848 字幕1 欢迎回家，本周六上午社区义诊        → 第 1 张图下面的字幕换成这句（中英文都行，“字幕1”后面的冒号会跳过）
  8848 字幕3                                     → 只写编号不写内容 = 第 3 张图恢复默认字幕（subtitles.txt 里的）
  - 回复“OK 这张图的字幕已更新”；翻到这张图时就滚动新字幕，样式和原来的字幕一样（浅底黑字），不是黄色通知条
  - 最多约 64 个汉字（太长会提示，只显示前面的）
  - 字幕开关（KEY3 长按 / 8848 字幕关）照样管用；有通知时显示通知，撤销通知后回到这张图的字幕；应急时显示应急字幕
  - 存在板上 Flash 的 0x101000 扇区（紧挨启事扇区），开机自动读回；要先装好字库
  - 原理：不另占片内存储，翻到这张图时 FPGA 用字库现场把字画进通知缓冲（约 2 毫秒）

启事（寻人 / 寻物 / 失物招领，最多 4 条，断电不丢）：
  8848 寻人 张大爷，男，75岁，身穿蓝色外套，下午在东门走失，请联系 138xxxxxxxx
  8848 寻物 黑色双肩包，内有笔记本电脑          （写成 8848 寻物启事：…… 也行，“启事”和冒号会跳过）
  8848 招领 拾到钥匙一串                          （8848 失物招领 …… 也行）
  8848 启事                                        串口回复现有的 4 条（原文），看是第几条
  8848 撤销2                                       撤销第 2 条（1~4）
  8848 撤销全部
  - 发布后马上插播一次（全屏启事页：标题栏按类别变色，寻人橙红 / 寻物蓝 / 招领绿，右上角“第几条/共几条”）
  - 之后自动轮播打开时：每张图放完，依次放全部启事（每条停一个轮播周期），再放下一张图
    自动轮播关（手动）时：只有新发布的那条插播一次，放完回到原来的图
  - 启事页上不显示字幕、波形和分辨率
  - 字号自动选：放得下就用大字（放大 2 倍，每行 18 个汉字，最多 4 行，约 72 个字）；
    放不下自动换小字（原大，每行 36 个汉字，最多约 127 个字）；比这还长会提示“只显示前面约 120 个字”
  - 4 条都满了再发会提示先撤销，不会自动挤掉旧的
  - 三级应急时启事照常插播、轮播；一级 / 二级应急接管，解除后接着放
  - 数码管左边显示 n2-3（正在放第 2 条，共 3 条）
  - 存在板上 Flash 的 0x100000 扇区（和字库、参数分开），每次发布 / 撤销都会重写，大约 0.1 秒
  - 页面底部一行提示按类别不同（寻人：请联系 / 拨打 110；寻物：拾到请交至服务中心；招领：失主带证件认领）
  - 底部提示和标题文字在 hdl_source/subtitle/page.txt 里改（F_PERSON / F_THING / F_FOUND），改完双击 gen_page.bat，TD 重新编译

启事照片（每条启事可以带一张照片，断电不丢）：
  1. 把照片（jpg / png / bmp 都行）拖到 gen_photo.bat 上（或者双击它再选文件）
     → 自动转正（手机照片的方向），整张照片缩放进 720×640 的框（小照片会放大），形状不一样的地方补白边，
       （想铺满不留白：用记事本打开 gen_photo.bat，把 -Mode fit 改成 -Mode crop（裁掉两边）或 -Mode stretch（拉伸））
       生成 PHOTO.BIN（约 900KB，RGB565）和 PHOTO_preview.png（屏上实际显示的样子，可以先看一眼）
  2. 先发布启事，再发：8848 照片1          （1~4 = 第几条启事，和屏幕右上角“第几条”一致）
  3. 等回复 READY（先擦 Flash，几秒钟）
  4. 60 秒内用串口助手的“文件”发送 PHOTO.BIN（921600 下大约 10 秒）
  5. 回复“OK 照片已装好，马上插播这条启事”，屏上马上插播一次带照片的启事页
  - 带照片的启事页：左边照片（FPGA 从 Flash 读出 720×640 原图，硬件 2×2 平均缩成 360×320），右边文字（大字每行 7 个字最多 6 行；放不下自动换小字，每行 14 个字最多 10 行）
  - 每次轮到带照片的启事，照片要从 Flash 重新读一遍，大约 0.7 秒，所以这一页出来会稍慢一点；这期间发来的串口指令优先处理（这一次就不显示照片）
  - 撤销这条启事、或者这个位置换成新启事，照片自动作废；同一条再发一次照片就是换照片
  - 照片存在 Flash 0x200000 起，每条 1MB（和字库、启事、参数分开）
  - 没有这条启事：回复“没有这一条启事”；传到一半断了 / 文件不对会提示，重新发一次即可

三级应急（设备不判断灾情，只执行管理员发的等级和类型）：
  8848 应急1 [类型] [内容]    一级 紧急撤离：红色闪烁边框 + 连续警笛，停止节目、锁定按键
  8848 应急2 [类型] [内容]    二级 就地避险：橙色闪烁边框 + 间歇提示音“嘀、嘀——”，停止节目、锁定按键
  8848 应急3 [类型] [内容]    三级 区域警戒：琥珀色细边框 + 右上角“区域警戒”标签，进入时“叮—咚”一声，节目和启事照常，普通通知暂停
  画面：一级显示 TF 卡上的 EMERG.BMP（疏散示意图，图片不被遮挡），没有这张图就显示内置红色警示页；
        二级始终显示内置橙色“就地避险”页（就地避险时不该看疏散路线）。内置页都是警示三角 + 中文大标题 + 提示语
  文字：串口发的文字（或类型 / 等级的提示语）在屏幕底部字幕条滚动（一级红底、二级橙底、三级黄底），不挡画面；
        按键 / 干接点进入时没有文字，字幕条显示固定的应急提示。按键进入和串口进入画面一样，只是底部文字不同
  8848 解除                   回到正常播放（之前的通知还在）
  类型：火灾 / 地震 / 治安 / 故障。只写类型不写内容，显示这一类的提示语；都不写，显示这一级的提示语：
    8848 应急1 火灾             → 发生火灾，请沿安全通道撤离，不要乘坐电梯
    8848 应急2                  → 请就地避险，留在安全区域，等待进一步通知
    8848 应急3 东门临时封闭，请走西门   → 显示你写的内容
  内容最多 3 行（每行 18 个汉字），放大 2 倍显示；提示语在 hdl_source/subtitle/cmd.txt 里可以改
  其他触发方式（和串口改的是同一个等级，谁后操作听谁的）：
    Key4 长按 1 秒：没有应急时进入一级应急；有应急（任何一级）时解除
    干接点（外部告警输入）：板子 J1 排针第 10 脚和第 12 脚（GND）短接 = 一级应急
      （代表消防主机 / 值班室紧急按钮的报警输出；接触 3 毫秒以上才算，防毛刺；断开不会自动解除，要按键或串口解除）
    这两种方式进入时没有串口文字：有 EMERG.BMP 就显示它，没有就显示内置警示页；底部字幕条显示固定的应急提示
  消音：应急接管（一级 / 二级）时短按 KEY3，或发 8848 消音 → 警报声和蜂鸣器停，画面告警不变；
        等级一变（升级、降级、解除）自动恢复声音；数码管 SOS 第二个 S 后面的小数点亮 = 已消音
  数码管：一级 / 二级应急时显示 SOS 和这次从触发到应急画面出现的实测时间（毫秒）

  - 通知：中文、英文、数字、标点都可以，最多约 64 个汉字（太长会截掉后面的并提示）
          黄底黑字在屏幕底部滚动，不受字幕开关控制；应急时（任何一级）让位给应急文字
  - 口令错了：回复“口令错误”，屏幕右上角红框“非法指令已拒绝”
  - 一级 / 二级应急里：音乐、翻页指令不执行；通知、字幕开关照常

第一次使用：装字库（只装一次，断电不丢）
  1. 双击 gen_font.bat 生成 FONT.BIN（已经生成好的话跳过；FONT_preview.png 可以看字体效果）
  2. 串口助手发送：8848 装字库
  3. 等回复 READY（先擦 Flash，大约 5 秒）
  4. 60 秒内用串口助手的“文件”发送 FONT.BIN（约 675KB，921600 下大约 8 秒）
  5. 回复“OK 字库安装完成，校验通过”就好了
  开机自检页最后一行“通知字库”显示绿色“已安装”。传到一半断了 / 文件不对会提示，重新装一次即可。

板上按键（SW2 拨开 = 参数菜单，这时四个键只调参数；SW4 拨开 = 左上角显示原图分辨率；SW1、SW3 不用）：
  Key1  短按 下一张                       按住 3 秒 复位
  Key2  短按 上一张                       长按 1 秒 进出缩略图
  KEY3  短按 音乐暂停 / 继续（应急时 = 消音）   长按 1 秒 字幕 开 / 关
  Key4  短按 自动轮播 开 / 关（缩略图里 = 选中）  长按 1 秒 一级应急 进入 / 解除
  KEY3 + Key2 同时按：音频波形 开 / 关（这次不算音乐暂停、翻页、缩略图）
  自动轮播、字幕、波形三个开关断电后保持（存在 Flash 参数区），第一次用默认都开

改口令 / 改关键字 / 改回复文字：
  hdl_source/subtitle/cmd.txt，改完双击 gen_cmd.bat 生成 cmd_rom.v，TD 重新编译

old_xtea_frame/ 是之前的二进制帧 + XTEA 认证版本（已不用，留着备查）
